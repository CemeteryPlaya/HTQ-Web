# Фронтенд

React + Vite, одностраничное приложение (~82k строк TypeScript, 88 страниц).
Раздаётся статикой в проде, через dev-сервер Vite в тестовых стеках.

---

## 1. Раскладка

```
frontend/src/
  api/         HTTP-клиент и описание эндпоинтов
  app/         маршрутизация и навигация
  components/  переиспользуемые компоненты и примитивы UI
  features/    крупные функциональные блоки (мессенджер)
  pages/       страницы (88 штук)
  hooks/       хуки
  lib/         утилиты, авторизация, WebRTC
  locales/     переводы
  data/        статические данные
  test/        настройка тестов
```

## 2. Маршрутизация

`frontend/src/app/routing/` — четыре файла с разделением обязанностей:

| Файл | О чём |
|---|---|
| `routeDefinitions.ts` | Списки маршрутов: публичные и защищённые |
| `lazyPages.ts` | Ленивая загрузка страниц |
| `prefetch.ts` | Предзагрузка |
| `types.ts` | Типы конфигурации маршрута |

### ⚠️ Пути в `protectedRoutes` обязаны быть уникальны

Это записано прямо в коде
(`frontend/src/app/routing/routeDefinitions.ts:18-24`) и стоило реального
инцидента.

`<Routes>` оценивает одинаковые строки пути **одинаково** и рендерит ту
запись, что объявлена **первой**. Дубликат молча затеняет более позднюю — и
именно так каждый маршрут `/admin/*` и `/hr/*` потерял свой `requiresRole`:
незащищённая копия стояла выше защищённой.

Сейчас от этого стоит сторож: `routeDefinitions.test.ts` **роняет сборку**,
если дубликат вернётся.

### Публичные маршруты

Помимо очевидных (`/login`, `/news`, `/contacts`) публичны две ссылки по
токену:

- `/public/org/:token` — оргструктура;
- `/public/employee/:token` — карточка сотрудника.

Их выдаёт `hr` через `share_link_service`, и каждое обращение пишется в
аудит: это персональные данные.

## 3. HTTP-клиент

`frontend/src/api/client.ts` — единая точка на Axios:

- подставляет JWT из `localStorage` в каждый запрос;
- при 401/403 пытается обновить токен и **повторить запрос**;
- публичные маршруты (регистрация, обратная связь) шлёт без токена;
- при 503 `service_disabled` поднимает событие через
  `frontend/src/lib/serviceUnavailableBus.ts`, и его показывает общий диалог.

Пути эндпоинтов не разбросаны по коду, а собраны в
`frontend/src/api/endpoints.ts` (`apiPath`).

---

## 4. Навигация — единый список

`frontend/src/app/navigation/navItems.ts` — **один** источник разделов для
залогиненного пользователя, общий для шапки и мобильной нижней панели.

Раньше списков было два, и они разошлись: из шапки стали недостижимы чаты,
почта и файлы. Не заводите второй.

Две функции:

| Функция | Что делает |
|---|---|
| `visibleNavItems({isEditor, isHr, hasTasks, hasDepartment})` | Отбирает разделы по правам |
| `splitForHeader(items, n)` | Делит на «в ряд» и «под кнопку Ещё» |

Порог у `splitForHeader` низкий намеренно: ряд делит место с логотипом,
поиском, бейджем мессенджера, уведомлениями, переключателем языка и кнопкой
профиля.

## 5. Права на фронте

`frontend/src/lib/auth/roles.ts` — предикаты `isEditor`, `isHrManager`,
`hasEmployeeTaskAccess`.

**Это удобство интерфейса, а не защита.** Проверка прячет кнопку, но не
запрещает запрос: токен лежит в браузере, и запрос отправляется руками.
Ограничение, существующее только здесь, — дефект безопасности. См.
[02-auth-rbac.md](02-auth-rbac.md), раздел 7.

---

## 6. Ленивая загрузка

Страницы грузятся лениво (`lazyPages.ts`). Тяжёлые компоненты, нужные только
залогиненному, тоже: уведомления, переключатель языка, модалка создания
задачи, глобальный поиск, бейдж мессенджера — последний открывает сокет,
поэтому гостю не нужен вовсе.

В шапке они дополнительно отложены таймером (`showDeferredControls`), чтобы не
конкурировать с первой отрисовкой.

## 7. Переводы

`frontend/public/locales/{ru,en}/translation.json`, i18next.

Соглашение: `t('ключ', 'запасной текст')`. Запасной текст показывается, если
ключа нет.

⚠️ В тестах i18n поднимается **с настоящими** русскими ресурсами
(`frontend/src/test/setup.ts`), а не с пустыми. Поэтому тест, ищущий элемент
по подписи, найдёт **перевод из файла**, а не запасной текст из кода. Если они
расходятся — тест падает, и это его законная работа: он ловит регресс «ключ
есть, перевод не тот».

## 8. Дизайн-система

shadcn/ui поверх Radix, Tailwind. Примитивы — `frontend/src/components/ui/`.

Правка примитива задевает всё приложение сразу: `dialog`, `input`, `select`,
`button`, `tabs`, `switch` используются везде.

## 9. Прокси Vite повторяет развилку nginx

`frontend/vite.config.ts` разводит запросы так же, как боевой nginx, чтобы
поведение стенда совпадало с продом.

Любопытная деталь: переменные `hrServiceTarget`, `tasksServiceTarget`,
`userServiceTarget` и прочие **все указывают на один и тот же**
`VITE_BACKEND_TARGET` (`frontend/vite.config.ts:80-85`). Имена остались от
FastAPI-поколения, где сервисы были разными процессами; сейчас они выжили
только потому, что таблица правил прокси по ним ключуется.

### ⚠️ `VITE_SFU_WS_TARGET` обязателен в тестовых стеках

Без него Vite шлёт `/ws/sfu` на дефолтный `127.0.0.1:4443` — то есть **в сам
контейнер фронта**. Сигналинг молча не находит SFU, страница открывается, а
связь не устанавливается. Симптом на причину не указывает.

В обоих `docker-compose.test-*.yml` переменная задана; при заведении нового
стека её легко забыть.

## 10. Команды

```bash
cd frontend
npm run dev                        # dev-сервер :3000
npm run build                      # сборка + проверка размера бандла
npm run lint                       # eslint
npx tsc --noEmit -p tsconfig.json  # проверка типов
npm test                           # vitest
npm run test:e2e                   # playwright
```

Playwright: chromium в окружении **не установлен**, запускайте с
`{ channel: 'msedge' }` — Edge есть на Windows-хосте.

Проверять изменения удобнее всего связкой `tsc --noEmit` + `npm test`: первая
ловит типы, вторая поведение.

## 11. Что ломается чаще всего

**Дубликат пути в `protectedRoutes`.** Молча снимает защиту с маршрута.
Сторож есть, но знать о ловушке нужно.

**Второй список навигации.** Разойдётся с первым, и часть разделов станет
недостижимой.

**Проверка прав только на фронте.** Не защита.

**Правка примитива `ui/`.** Задевает всё приложение; прогоняйте полную сюиту.

**Расхождение подписи в коде и в переводах.** Тест ищет по переводу из файла.
