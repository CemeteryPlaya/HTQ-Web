# Домен `hr` → `apps.hr` — план переноса (Поток A, фаза A1)

> **For agentic workers:** REQUIRED SUB-SKILL — superpowers:subagent-driven-development. Шаги —
> чекбоксы (`- [ ]`). Детализация задач 1–2 полная (по ним стартует A1); задачи 3+ (эндпойнты по
> роутерам) детализируются just-in-time перед своим исполнением — их контракт снимается с
> FastAPI-исходника и с реальных вызовов фронта, гадать заранее нельзя.

**Goal:** перенести FastAPI-сервис `services/hr` в изолированную отключаемую Django-аппку
`apps.hr` с полным паритетом контракта, и отдать соседям (Поток B) стабильный `apps.hr.interface`.

**Architecture:** одна Django-аппка `apps.hr` (схема `public`, `managed=True`, натуральные
миграции). Бизнес-логика — в `apps/hr/services/<домен>_service.py`, роутеры-вьюхи тонкие
(`htqweb.http.api_view`). Данные пользователя — только через `apps.users.interface` (Р2:
`user_identity_sync` умирает). Файлы — через `apps.media_files.interface`. HR-документы из Mongo
переезжают в PostgreSQL JSONB.

**Tech Stack:** Python 3.14, Django 5.2.7, PostgreSQL, `htqweb.http.api_view`, `htqweb.authn`,
Celery. Кандидаты (подтверждаются при реальном использовании): `django-import-export`+`openpyxl`
(штатка/T-2), `docxtpl` (генерация документов).

## 2. Сквозные решения

- **D1. `ltree` не нужен.** `Department.path` в исходнике — обычный `String(500)` с отдельным
  индексом (комментарий «ltree stored as plain text (requires ltree extension)» вводит в
  заблуждение: расширение не используется, тип колонки строковый). Портируем как
  `CharField(max_length=500, unique=True)`. `django-tree-queries` и raw-SQL иерархии **не берём** —
  обход дерева идёт по строковому префиксу пути, как в оригинале.
- **D2. Имена таблиц — дефолтные Django** (`hr_department`, `hr_position`, …), а не старые
  `hr_departments`. Это прямое следствие решения «идиоматичный Django с нуля» (PLAN.md §3).
  Соответствие старое→новое фиксируется в §5 и используется ETL (фаза 10).
- **D3. Циклический FK.** `Department.manager → Employee` и `Employee.department → Department`
  (в исходнике `use_alter=True`). `manager` nullable → Django-автодетектор сам разложит на
  `CreateModel` + `AddField`. Специальных приседаний не требуется; проверяется сборкой на пустой БД.
- **D4. Индексы: без дублей.** Там, где в исходнике одновременно `unique=True` и отдельный
  `Index(...)` по той же колонке (`hr_departments.path`, `hr_positions.weight`,
  `hr_level_thresholds.level_number`), Django-`unique=True` уже создаёт уникальный индекс —
  второй, неуникальный, **не воспроизводим** (он избыточен и в оригинале). Все прочие
  `Index(...)` → `db_index=True`. Решение зафиксировано здесь, чтобы ревью не считало это потерей.
- **D5. `OrgSettings` — не `BaseModel`.** Наследует `Base` напрямую: есть `id`, `key`, `value`,
  `description`, `updated_at`, и **нет `created_at`**. Не подставлять общую базу автоматически.
- **D6. Mongo → JSONB.** Две Django-модели: `EmployeeDocumentBlob` (ex-`hr_documents` коллекция:
  `employee_id` int + `doc_type` + `data JSONField` + `created_at`, индексы по `employee_id`,
  `doc_type`, составной) и `EmployeeGroups` (ex-`hr_employee_groups`: `employee_id` unique +
  `data JSONField`). Эндпойнты `mongo_documents.py` и `employee_card.py:/groups` читают/пишут их.
  **Сам перелив данных — фаза 10 (A4)**, здесь только модели + эндпойнты.
- **D7. Связь с пользователем.** `Employee.user_id` остаётся обычным `IntegerField(unique=True,
  null=True)` — **не FK** на `apps.users.User` (межаппные FK запрещены). Данные пользователя —
  через `apps.users.interface.get_user_brief/get_users_brief`. `user_identity_sync` не портируем (Р2).
- **D8. Файлы.** `department_files` и вложения — через `apps.media_files.interface.store_file(...)`,
  scope `hr_department`/`hr_doc`. Эти scope'ы **ограничены** (`RESTRICTED_SCOPES`) и требуют
  `internal_authorized=True` — hr вызывает их как доверенный внутренний потребитель, и в этой фазе
  уточняет реальную ролевую проверку (seam Д1 в `scope_policy.authorize_scope_write`).
- **D9. Перевод оргдерева (LibreTranslate)** — за настройкой, сеть в тестах не дёргаем
  (пустая настройка → no-op, как `TRANSLATION_API_KEY` в cms).

```python
"""Паритет схемы hr-core с FastAPI-исходником (services/hr/app/models/).

Проверяет то, что реально ломалось в прошлых фазах: потерянные индексы,
потерянные СЕРВЕРНЫЕ дефолты (NOT NULL без db_default роняет вставку мимо ORM),
nullability и uniqueness. Плюс живой round-trip через БД.
"""
import datetime

import pytest
from django.db import connection

from apps.hr.models import Department, Employee, LevelThreshold, OrgSettings, Position


def _cols(table: str) -> dict:
    with connection.cursor() as cur:
        cur.execute(
            "SELECT column_name, is_nullable, column_default "
            "FROM information_schema.columns WHERE table_name = %s", [table])
        return {r[0]: {"nullable": r[1] == "YES", "default": r[2]} for r in cur.fetchall()}


def _indexed_columns(table: str) -> set[str]:
    with connection.cursor() as cur:
        cur.execute("SELECT indexdef FROM pg_indexes WHERE tablename = %s", [table])
        defs = [r[0] for r in cur.fetchall()]
    return {d.split("(")[-1].split(")")[0].strip().strip('"') for d in defs}


@pytest.mark.django_db
def test_timestamps_have_server_defaults():
    # created_at/updated_at NOT NULL с server_default=now() в исходнике
    # (models/base.py). Без db_default вставка мимо ORM упадёт.
    for table in ("hr_department", "hr_position", "hr_employee"):
        cols = _cols(table)
        assert cols["created_at"]["default"] is not None, table
        assert cols["updated_at"]["default"] is not None, table
        assert not cols["created_at"]["nullable"], table


@pytest.mark.django_db
def test_department_columns_and_indexes():
    cols = _cols("hr_department")
    assert not cols["name"]["nullable"]
    assert not cols["path"]["nullable"]
    assert cols["description"]["nullable"]
    assert cols["manager_id"]["nullable"]
    assert cols["is_active"]["default"] is not None
    assert cols["unit_type"]["default"] is not None
    assert {"name", "path"} <= _indexed_columns("hr_department")


@pytest.mark.django_db
def test_position_indexes_ported():
    # исходник: Index по weight, level, is_system (+ weight unique)
    assert {"weight", "level", "is_system"} <= _indexed_columns("hr_position")


@pytest.mark.django_db
def test_employee_user_id_unique_and_nullable():
    cols = _cols("hr_employee")
    assert cols["user_id"]["nullable"]          # связь с users опциональна
    assert "user_id" in _indexed_columns("hr_employee")


@pytest.mark.django_db
def test_org_settings_has_no_created_at():
    # D5: OrgSettings наследует Base, а не BaseModel — created_at нет.
    assert "created_at" not in _cols("hr_org_settings")
    assert "updated_at" in _cols("hr_org_settings")


@pytest.mark.django_db
def test_level_threshold_range_constraint_enforced():
    from django.db.utils import IntegrityError
    with pytest.raises(IntegrityError):
        LevelThreshold.objects.create(level_number=1, weight_from=10, weight_to=5)


@pytest.mark.django_db
def test_core_roundtrip_with_circular_manager_fk():
    # D3: Department.manager -> Employee, Employee.department -> Department
    dep = Department.objects.create(name="ИТ", path="it", unit_type="department")
    pos = Position.objects.create(title="Инженер", department=dep, weight=100, level=2)
    emp = Employee.objects.create(
        first_name="Иван", last_name="Иванов", email="i@htq.test",
        department=dep, position=pos, hire_date=datetime.date(2024, 1, 9),
    )
    dep.manager = emp
    dep.save(update_fields=["manager"])
    dep.refresh_from_db()
    assert dep.manager_id == emp.id
    assert emp.status == "active"          # дефолт из исходника
    assert emp.is_deleted is False
    assert OrgSettings.objects.create(key="deletion_strategy", value="cascade").id
```

```python
"""Модели домена hr. Порт services/hr/app/models/ (см. docs/plans/2026-07-20-hr-domain.md).

Имена таблиц — дефолтные Django (D2): hr_department, hr_position, ... Старые имена
(hr_departments, ...) остаются только в карте ETL фазы 10.
"""
from django.db import models
from django.db.models.functions import Now


class HrBase(models.Model):
    """Порт services/hr/app/models/base.py::BaseModel.

    created_at/updated_at — NOT NULL с СЕРВЕРНЫМ дефолтом (server_default=func.now()
    в исходнике). db_default обязателен: без него вставка мимо ORM (ETL, raw SQL)
    упадёт на NOT NULL. auto_now воспроизводит onupdate=func.now().
    """
    created_at = models.DateTimeField(db_default=Now())
    updated_at = models.DateTimeField(db_default=Now(), auto_now=True)

    class Meta:
        abstract = True


class UnitType(models.TextChoices):
    DEPARTMENT = "department", "Отдел"
    DIVISION = "division", "Управление"
    GROUP = "group", "Группа"


class EmployeeStatus(models.TextChoices):
    ACTIVE = "active", "Работает"
    INACTIVE = "inactive", "Неактивен"
    TERMINATED = "terminated", "Уволен"


class Department(HrBase):
    name = models.CharField(max_length=255, unique=True)
    # D1: в исходнике это String(500) с обычным индексом, НЕ PG-ltree.
    # Иерархия — строковый путь; обход по префиксу.
    path = models.CharField(max_length=500, unique=True)
    description = models.TextField(null=True, blank=True)
    # D3: циклический FK (в исходнике use_alter=True). nullable -> Django
    # разложит на CreateModel + AddField сам.
    manager = models.ForeignKey(
        "hr.Employee", null=True, blank=True, on_delete=models.SET_NULL,
        related_name="managed_department",
    )
    is_active = models.BooleanField(default=True, db_default=True)
    unit_type = models.CharField(
        max_length=20, choices=UnitType.choices,
        default=UnitType.DEPARTMENT, db_default=UnitType.DEPARTMENT.value,
    )

    def __str__(self) -> str:
        return self.name


class Position(HrBase):
    title = models.CharField(max_length=255, unique=True)
    department = models.ForeignKey(Department, on_delete=models.CASCADE,
                                   related_name="positions")
    grade = models.IntegerField(default=1, db_default=1)
    description = models.TextField(null=True, blank=True)
    requirements = models.JSONField(null=True, blank=True)
    is_active = models.BooleanField(default=True, db_default=True)
    # Меньший вес = выше в иерархии (0 = верх). Глобально уникален.
    weight = models.IntegerField(unique=True, default=100, db_default=100)
    # Кэш из hr_level_threshold; пересчитывается при смене weight.
    level = models.IntegerField(default=2, db_default=2, db_index=True)
    is_system = models.BooleanField(default=False, db_default=False, db_index=True)
    # {"hr_level": "junior|middle|senior|lead", "permissions": [str, ...]}
    permissions = models.JSONField(null=True, blank=True)

    def __str__(self) -> str:
        return self.title


class Employee(HrBase):
    # D7: связь с apps.users — обычный int, НЕ межаппный FK.
    user_id = models.IntegerField(null=True, blank=True, unique=True)
    first_name = models.CharField(max_length=100)
    last_name = models.CharField(max_length=100)
    middle_name = models.CharField(max_length=100, null=True, blank=True)
    email = models.CharField(max_length=255, unique=True)
    phone = models.CharField(max_length=20, null=True, blank=True)
    department = models.ForeignKey(Department, on_delete=models.PROTECT,
                                   related_name="employees")
    position = models.ForeignKey(Position, on_delete=models.PROTECT,
                                 related_name="employees")
    hire_date = models.DateField()
    termination_date = models.DateField(null=True, blank=True)
    status = models.CharField(max_length=20, choices=EmployeeStatus.choices,
                              default=EmployeeStatus.ACTIVE,
                              db_default=EmployeeStatus.ACTIVE.value)
    avatar_url = models.CharField(max_length=500, null=True, blank=True)
    bio = models.TextField(null=True, blank=True)
    is_deleted = models.BooleanField(default=False, db_default=False)

    def __str__(self) -> str:
        return f"{self.last_name} {self.first_name}"


class LevelThreshold(HrBase):
    level_number = models.IntegerField(unique=True)
    weight_from = models.IntegerField()
    weight_to = models.IntegerField()
    label = models.CharField(max_length=100, null=True, blank=True)
    color = models.CharField(max_length=7, null=True, blank=True)

    class Meta:
        constraints = [
            models.CheckConstraint(condition=models.Q(weight_from__lte=models.F("weight_to")),
                                   name="ck_threshold_range"),
            models.CheckConstraint(condition=models.Q(level_number__gte=1),
                                   name="ck_threshold_level_positive"),
        ]


class OrgSettings(models.Model):
    """D5: наследует models.Model, НЕ HrBase — в исходнике нет created_at."""
    key = models.CharField(max_length=100, unique=True)
    value = models.CharField(max_length=500)
    description = models.TextField(null=True, blank=True)
    updated_at = models.DateTimeField(db_default=Now())
```

```python
def get_department_brief(department_id: int) -> dict | None:
    require_service("hr")
    row = (Department.objects.filter(id=department_id)
           .values("id", "name", "path", "is_active").first())
    return row


def get_departments_brief(department_ids: list[int]) -> list[dict]:
    require_service("hr")
    return list(Department.objects.filter(id__in=list(department_ids))
                .values("id", "name", "path", "is_active"))


def get_employee_brief(user_id: int) -> dict | None:
    require_service("hr")
    row = (Employee.objects.filter(user_id=user_id, is_deleted=False)
           .select_related("position")
           .values("id", "first_name", "last_name", "department_id",
                   "position__title", "status").first())
    if row is None:
        return None
    return {
        "id": row["id"],
        "full_name": f"{row['last_name']} {row['first_name']}",
        "department_id": row["department_id"],
        "position_title": row["position__title"],
        "status": row["status"],
    }


def org_ancestors(department_id: int) -> list[dict]:
    """Предки отдела от корня к непосредственному родителю (себя не включая).

    D1: path — строковый путь ("it.dev.backend"), не ltree. Предки — это
    префиксы пути, поэтому один запрос по path__in, без рекурсии.
    """
    require_service("hr")
    dep = Department.objects.filter(id=department_id).values("path").first()
    if dep is None:
        return []
    parts = dep["path"].split(".")
    prefixes = [".".join(parts[:i]) for i in range(1, len(parts))]
    if not prefixes:
        return []
    by_path = {d["path"]: d for d in Department.objects.filter(path__in=prefixes)
               .values("id", "name", "path", "is_active")}
    return [by_path[p] for p in prefixes if p in by_path]
```
