## 1. Решения (до или после деплоя — по выбору)

Расхождения с ТЗ, на которые нет решения в реестре мастер-плана. По каждому — либо решение «так и оставляем» (строка в реестре решений), либо задача A.

| # | Что | ТЗ | Сейчас в коде |
|---|---|---|---|
| Р1 | IP и user-agent в журнале изменений документов | §25.2 | у `bpp.AuditLog` этих полей нет; есть только в журнале файлов `FileEvent` |
| Р2 | Хеширование паролей bcrypt или argon2 | §27 | `PASSWORD_HASHERS` не задан — Django PBKDF2; пакет `bcrypt` в зависимостях есть |
| Р3 | Сессия 8 ч, выход после 60 мин бездействия | §27 | JWT: access 60 мин, refresh 7 дней; отзыв refresh при смене пароля отложен (см. A3) |
| Р4 | Технические логи — 90 дней | §27 | Loki хранит 14 дней (`retention_period: 336h`, `infra/logging/loki-config.yml`) |
| Р5 | Сообщение E-SYS-01 на фронте («Сервер не отвечает… черновик сохранён в браузере») | каталог ошибок | на бэкенде код есть (молчащий антивирус), текста на фронте нет |
| Р6 | E-VAT-01 для счёта: «нет ставки — отправка запрещена» | BR-031, D-14 | проверка есть только у договора; у счёта при отсутствии ставки — 16 % по D-14 |
| Р7 | Размер запроса ≤ 25 МБ | §27 | файлы модуля — 21 МБ, но `/api/media/` принимает 100 МБ (платформа) |
| Р8 | Включение ClamAV на бою | §21 [Л], D-S7-6 | сделано, выключено; включение — [ранбук антивируса](../deploy/antivirus-runbook.md) |
| Р9 | Синхронизация с 1С: имена справочников и реквизитов OData | D-38, D-S7-5 | заготовка без запуска; `FIELD_MAP` — предположение, ждём администратора 1С |
| Р10 | Реальные примеры выписок банков | В-13, D-S3-3 | парсеры проверены на синтетике; образцов в `docs` нет |
