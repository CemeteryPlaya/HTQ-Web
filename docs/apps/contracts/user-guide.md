# Contracts user guide

## Before you begin

Make sure the required reference data exists:

1. Country and administrator for the budget context.
2. Program for each budget line.
3. Counterparty and, where required, contact details.

The application is available from **Contracts** in the main navigation. The left navigation groups work into budgets and reference data, agreement work, and expenses without an agreement.

## Plan a budget

1. Open **Budgets** and create a budget, using the applicable administrator and period.
2. Add a budget line for each program that will receive funds.
3. Review the budget detail page to see related agreements, invoices, and accountable-funds requests.
4. Submit the budget when it is ready for review.

Use the budget detail page as the financial context: it shows which related records affect the remaining amount. Draft or otherwise non-committing records may be displayed as outside the remaining balance.

## Register a counterparty

1. Open **Counterparty register**.
2. Create the counterparty and enter its required registration and tax details.
3. Add contact information if it will be used for agreement work.
4. Submit the record if your workflow requires approval.

Create or correct counterparties before starting an agreement or invoice. That avoids orphaned financial records and makes the record available for selection elsewhere in the application.

## Run an agreement workflow

1. Create an agreement and assign its budget, budget line, and counterparty.
2. Upload the agreement file when it is available.
3. Submit the agreement for the configured approval process.
4. Record any advance payments, contract payments, and completion acts against the agreement.
5. Upload supporting payment-order, invoice, or act files from the respective record.

The agreement detail view is the best place to review related payments and completion acts together.

## Record an expense without an agreement

Choose the route that matches the expense:

- **Invoices without an agreement**: create the invoice, link its budget context and counterparty, attach its file, then submit it.
- **Accountable funds**: create a request for the accountable employee, submit it, assign the budget line where permitted, and have accounting mark it paid. Add an advance report to close out the amount spent.

## Follow up on work

Use **Waiting for me** for Contracts actions assigned to the current user. Use the shared signoff interface to make approval decisions. If a record cannot be submitted or moved forward, check its required links, attached document, current status, and your assigned permissions.
